# Статус ML-инфраструктуры (Art Visor)

## 🏗️ 1. Развернутая инфраструктура (Docker)
Все базовые сервисы подняты и настроены для работы:
* **MinIO (S3 хранилище):** Создан бакет `dataset`. Локальный датасет (56 000+ изображений WikiArt по 27 стилям) успешно отзеркалирован с сохранением структуры папок.
* **PostgreSQL (Векторная БД):** Включено расширение `pgvector`. Создана таблица `artworks`. Настроен сверхбыстрый индекс **HNSW** (`vector_cosine_ops`) для поиска по 768-мерным векторам.
* **RabbitMQ (Брокер сообщений):** Настроена авторизация по `.env`. Воркер успешно создает и слушает очереди `art.analysis.queue` (входящие задачи) и `art.results.queue` (исходящие результаты).

## 🗄️ 2. Миграция данных (Датасет)
Многочасовой процесс генерации векторов был пропущен благодаря использованию кэша:
* Успешно прочитан архив `embeddings.npz`.
* Извлечено **56 762 записи** (векторы, пути к файлам, стили).
* Сформированы валидные S3-ссылки.
* Выполнена пакетная вставка (batch insert) всех 56к записей в таблицу `artworks`.
* **Тест пройден:** SQL-запрос косинусного расстояния (`<=>`) успешно находит визуально похожие картины менее чем за секунду.

## 🧠 3. ML-Worker (Python)
Написан, отлажен и протестирован изолированный Python-микросервис (`worker.py`). 

**Что он умеет:**
1. Слушает очередь RabbitMQ в ожидании JSON-задач с URL картинок.
2. Безопасно скачивает изображения (с подменой `User-Agent` для обхода блокировок серверов вроде Википедии).
3. Прогоняет изображение через **CLIP** (`openai/clip-vit-large-patch14`) и извлекает нормализованный 768-мерный эмбеддинг.
4. Классифицирует стиль картины (топ-5 вероятностей) с помощью обученной scikit-learn модели (`minimalism_classifier.pkl`).
5. Извлекает палитру из 5 доминирующих цветов (HEX) с помощью алгоритма **K-Means**.
6. Собирает всё это в финальный JSON и отправляет обратно в RabbitMQ.

**Статус:** Воркер работает стабильно, ошибки форматов тензоров и сетевые блокировки устранены.
